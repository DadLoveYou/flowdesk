# FlowDesk 项目内容梳理

## 一句话介绍

FlowDesk 是一套企业业务申请与审核工作台。业务专员提交采购、服务开通、资质备案等申请，审核员处理，管理员管理成员和查看操作日志。

它把项目 3 的权限、动态表单和断点续传放进一个有明确业务价值的完整流程，能够用三个角色连续演示。

## 页面与业务闭环

| 页面       | 解决的问题             | 主要交互                                           |
| ---------- | ---------------------- | -------------------------------------------------- |
| 登录       | 进入对应角色的工作空间 | 账号登录、演示角色快捷入口、会话恢复               |
| 工作台     | 快速了解当前业务进展   | 统计、七天趋势、待办跳转、最近申请、动态           |
| 申请管理   | 查找和跟进业务申请     | 状态标签、关键词、类型筛选、排序、分页、CSV 导出   |
| 新建/编辑  | 完善业务信息和材料     | 条件字段、跨字段校验、异步校验、自动草稿、附件关联 |
| 申请详情   | 查看当前状态和历史过程 | 业务内容、附件下载、编辑、审核、流转时间线         |
| 审核中心   | 处理等待审核的事项     | 默认待审核筛选、通过、退回、审核意见               |
| 文件中心   | 管理上传材料           | 拖拽上传、暂停、继续、刷新续传、秒传、下载         |
| 账号与权限 | 维护团队成员的职责边界 | 新增成员、变更角色、停用、会话失效                 |
| 操作日志   | 追溯关键行为           | 登录、申请流转、上传完成、权限变更、搜索和分页     |

## 三个角色的边界

管理员可以查看全空间业务及日志、管理成员、创建申请和审核他人的申请。审核员可查看全空间业务与附件、处理审核，但不能创建申请、管理账号或读取日志。业务专员只能访问自己的申请与文件。

三个角色的预算**列表列**不同：管理员和审核员显示预算列，专员列表隐藏。专员在自己的申请表单和详情中仍可填写、查看预算；这不是对本人预算进行保密。

任何人都不能审核自己提交的申请。管理员也不能编辑别人的申请；管理员审核和数据查看能力不等于代替申请人修改业务内容。

## 表单引擎具备什么能力

`src/lib/form-fields.json` 定义字段类型、标题、提示、必填标识、选项与显示条件；`SchemaFields.vue` 负责统一渲染和事件。

- 企业主体显示企业名称、信用代码；个人主体隐藏这两项。
- 采购申请显示预算；超过 20,000 元显示预算依据并要求至少 10 字。
- 结束日期不能早于开始日期，服务器同时拒绝不存在的日期。
- 企业资质备案必须关联上传完成的执照材料；这里验证材料是否存在，不自动识别执照真实性。
- 信用代码为 18 位大写字母或数字，重复校验针对审核中或已通过的资质备案；这里未实现官方信用代码校验位算法。
- 异步校验取消过期请求，提交时服务器再次执行检查。

这是一套**JSON 配置的表单引擎**。显示条件使用白名单比较运算符，没有提供任意用户输入脚本执行、在线表单设计器或 JSON Schema 全规范支持。

## 草稿与文件

本地草稿按 `用户 ID:申请 ID/新建` 保存，600 ms 防抖；刷新后先提示恢复，不静默覆盖当前表单。手动保存草稿写入数据库，能够跨设备继续。已完成提交后清除对应本地草稿。

文件在独立 Worker 内按 2 MB 读取计算 MD5，主线程保持可交互。一个文件最多 3 个分片请求并发，多文件任务顺序执行以限制总体并发。暂停通过 AbortController 取消请求；恢复前重新读取服务器已接收分片，避免客户端猜测完成进度。刷新后重新选择同一份原文件，重新计算指纹即可找到原上传任务。

服务器校验分片大小、所有权和索引，按顺序合并、校验文件大小与整个文件的 MD5，再标记完成。指纹相同的已完成文件在同一账号范围内复用。未完成文件不能关联为申请附件。
